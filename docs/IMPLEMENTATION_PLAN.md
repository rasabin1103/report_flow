# Implementation plan
1. Foundation: strict versioned schemas, bounded CSV/XLSX ingestion and inspection.
2. Analytics: typed filters, selected columns, grouped metrics and KPIs.
3. PDF: reusable typography, two templates, cover, summary, charts, paginated tables, methodology.
4. Transport: shared services, REST and Typer CLI, integration tests.
5. Hardening: worker deadlines, limits, safe branding, Docker, CI, docs and visually reviewed examples.
